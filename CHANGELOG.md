# Changelog

## 1.3.0 — 2026-07-17

- Renamed the product to Costco Receipt Organizer across the app, installer, windows, generated PDFs, and documentation.
- Added automatic migration from the former `Receipt` application-data directory while preserving the old folder as a rollback copy.
- Removed private seed receipt data from packaged builds and expanded public-repository ignore rules.
- Enabled ASAR packaging and an ad-hoc macOS integrity signature for the local distribution build.
- Added public documentation for privacy, security, provenance, installation, and local architecture.
- Retained the complete item, receipt, refund, discount, tax, metadata, sync, cart, and price-match feature set.

## 1.2.0

- Added Canada and U.S. Costco digital-receipt sync, native product-enrichment browser, refund and quantity handling, receipt cart, public deal checks, fixed-shell data tables, and Apple Silicon DMG packaging.
